## 【开场白 — 30秒】

大家好，我今天要讲的项目叫 **合家云社区物业管理平台**。它是一个**前后端分离**的 Web 项目——后端用 Spring Boot，前端用 Vue 2 + Element UI。

**一句话总结：** 物业公司可以用这个系统来管理所有小区的信息，包括小区的新增、修改、删除、搜索、导出 Excel，同时还包含完整的用户权限管理功能。

项目放在 `E:\idea_workscope\HejiayunCommunity` 下。

## 三、后端详解 — 2分钟

### 包结构（4 层）

```
common/      → 公共层（工具类、统一响应、异常处理）
framework/   → 框架层（Security配置、JWT过滤器、跨域）
system/      → 系统管理层（用户、角色、菜单、字典）
community/   → 业务层（小区管理）
web/         → 控制层（所有 API 接口）
```

**common 公共层：** 所有模块共享的代码。
- `BaseResponse`：统一响应格式 `{code, msg, data, success}`
- `BaseEntity`：实体基类（createTime、updateTime 自动填充）
- `GlobalExceptionHandler`：全局异常处理，不会把 Java 报错暴露给用户

**framework 框架层：** 核心安全配置。
- `SecurityConfig`：哪些接口公开（`/login`、`/captchaImage`），哪些需要登录
- `JwtAuthenticationTokenFilter`：每个请求进来先经过它，解析 Token、从 Redis 取出用户信息

**community 业务层：** 小区实体包含名称、编码、省市区划、详细地址、经纬度、所属物业公司。

## 六、权限控制怎么实现的 — 1分钟

这是这个项目的一个重点，**前后端双重权限控制**。

### 后端权限

在 Controller 的方法上加注解：

```java
@PreAuthorize("@pe.hasPermission('system:community:list')")
public PageResult communityList() { ... }
```

用户登录的时候，系统会查这个用户有哪些角色 → 角色有哪些菜单权限 → 把这些权限存到 Redis 里。每次请求时，JWT 过滤器会从 Redis 取出来，Spring Security 自动对比。

### 前端权限

用 `v-hasPermi` 指令控制按钮显示：

```html
<el-button v-hasPermi="['system:community:add']">新增</el-button>
```

如果当前用户没有这个权限，按钮就不渲染。

### 前端路由权限

`permission.js` 从后端 `/getRouters` 接口获取可访问的路由列表，动态生成路由表。没有权限的页面不会出现在侧边栏，直接访问也会跳转到 401 页面。

## 九、亮点与不足 — 1分钟

### 亮点（6个重点）

1. **前后端分离架构** — Vue + Spring Boot 标准模式
2. **RBAC 双重权限控制** — 后端 `@PreAuthorize` + 前端 `v-hasPermi`
3. **Token 自动刷新** — 30分钟有效，<20分钟自动续期
4. **前端页面完整** — 登录/仪表盘/小区CRUD/系统管理/监控/工具，页面齐全
5. **字典缓存** — 常量数据存 Redis，支持清空缓存
6. **一键导出 Excel** — EasyPOI 导出

### 不足

1. **缺少 SQL 建表脚本** — 需要手动建表
2. **JWT 密钥硬编码** — 应该用环境变量
3. **缺少单元测试**
4. **Java 版本不统一**

## 附：答疑准备

### Q1：前后端怎么通信的？
前端请求路径加 `/hejiayun` 前缀，`vue.config.js` 里配了代理，转发到 `localhost:8080`。Axios 请求拦截器会自动带上 Token。

### Q2：权限怎么控制的？
双重控制。后端用 `@PreAuthorize` 注解拦截接口；前端用 `v-hasPermi` 指令控制按钮显示，`permission.js` 控制路由访问。

### Q3：项目现在能跑起来吗？
能。先启动 MySQL 和 Redis，然后 `mvn spring-boot:run` 启动后端，再 `npm run dev` 启动前端，浏览器打开 `http://localhost` 就能看到登录页。

### Q4：你怎么学 Spring Security 的？
先用 `springsecurity_example2` 学表单登录，再用 `springsecurity_example` 学 JWT + 注解权限，最后整合到主工程里。

### Q5：前端的页面有哪些？
登录页、首页仪表盘（图表）、小区管理（CRUD+导出）、系统管理（用户/角色/菜单/部门/字典/公告）、物业管理（楼宇/房屋/业主/报修/访客）、系统监控（日志/缓存/服务器）、代码生成等，共 20 多个页面。
