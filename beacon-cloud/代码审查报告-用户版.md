# beacon-cloud 代码审查报告 - 用户版

> 面向开发者，按优先级排列，只列问题和修复建议

---

## P0 - 必须修复（影响资金安全/稳定性）

### 1. 扣费非原子性 — 资损风险
**文件**: `beacon-strategy/.../FeeStrategyFilter.java`

先扣钱，再判断，不够再回滚。三步不是原子的，中间宕机会丢钱。

**修复**: 用 Redis Lua 脚本保证原子性。

---

### 2. ConcurrentHashMap 内存泄漏 — OOM 风险
**文件**: `beacon-common/.../CMPPSubmitRespMapUtil.java`
**文件**: `beacon-common/.../CMPPDeliverMapUtil.java`

静态 Map 只在收到响应时 remove。运营商不回复（网络故障）则 Entry 永远不清理，持续累积导致 OOM。

**修复**: 用 Caffeine/Guava Cache 带 TTL 过期，或存 Redis。

---

### 3. 限流并发缺陷 — 误杀正常用户
**文件**: `beacon-strategy/.../LimitOneMinuteStrategyFilter.java`
**文件**: `beacon-strategy/.../LimitOneHourStrategyFilter.java`

先插入再查询，高并发下两条都可能插入成功，然后各自查到 count>=2，两条都被拒绝。

**修复**: 用 Redis Lua 脚本保证原子操作。

---

### 4. 限流写 Redis 无法回滚
**文件**: `beacon-strategy/.../LimitOneMinuteStrategyFilter.java` (L60)
**文件**: `beacon-strategy/.../LimitOneHourStrategyFilter.java` (L62)

分钟限流先写入 Redis，然后小时限流判断拒绝。分钟写入无法撤回，导致用户真的发了短信却被拒绝，且 Redis 里留了脏数据。

**修复**: 策略链入口做快照，失败时批量清理限流写入；或改用 Lua 先判断再写入。

---

### 5. Netty 重连阻塞 IO 线程 + 无退避
**文件**: `beacon-SmsGateway/.../HeartHandler.java` (L41-L44)
**文件**: `beacon-SmsGateway/.../NettyClient.java` (L73-L96)

`channelInactive` 在 Netty IO 线程上同步调用 `reConnect(10)`，阻塞事件循环。且每次断线固定 10 次 × 10 秒，无指数退避。

**修复**: 异步执行重连，加指数退避（1s, 2s, 4s...）。

---

## P1 - 强烈建议修复

### 6. Feign Client 方法签名冲突
**文件**: `beacon-api/.../BeaconCacheClient.java`

四个方法使用完全相同的 URL + GET 方法，Feign 无法区分，运行时行为不可预期。

**修复**: 给每个方法不同路径，或用 `@RequestParam` 区分。

---

### 7. 雪花算法运算符优先级 Bug
**文件**: `beacon-common/.../SnowFlakeUtil.java` (L154-L158)

`sequence & Long.MAX_VALUE` 优先级高于 `|`，等价于 `(sequence & Long.MAX_VALUE) | ...`。虽然 sequence 本身不会负、实际影响小，但这是经典 bug。

**修复**: 加括号 `(sequence & Long.MAX_VALUE)`。

---

### 8. 雪花算法时间回拨直接抛异常
**文件**: `beacon-common/.../SnowFlakeUtil.java` (L123-L127)

NTP 时间回拨时直接 throw，整个服务不可用。

**修复**: 等待回拨时间过去（阻塞等待），或改用分布式 ID 服务。

---

### 9. CMPP 协议字节数组越界风险
**文件**: `beacon-SmsGateway/.../CMPPDecoder.java` (L25-L33)

`totalLength` 来自网络数据，如果大于实际收到字节数，`subarray` 截断后后续解析全是垃圾数据，不抛异常。

**修复**: 加长度校验，`totalLength > buf.length` 时丢弃或断开。

---

### 10. CMPP 编码格式硬编码
**文件**: `beacon-SmsGateway/.../CmppSubmit.java` (L107) — msgFmt 写死为 8 (UCS2)
**文件**: `beacon-SmsGateway/.../CmppDeliver.java` (L19) — Msg_Fmt 写死为 15 (GB2312)

**修复**: 从 Redis 或 Nacos 配置中读取。

---

### 11. Netty 连接配置硬编码 + 密码明文
**文件**: `beacon-SmsGateway/.../NettyStartCMPP.java`

host/port/serviceId/pwd 全部硬编码，密码明文在源码中，多实例部署有问题。

**修复**: 迁移到 Nacos 配置中心，敏感信息走环境变量。

---

## P2 - 建议改进

### 12. BeanUtils.copyProperties 字段不一致
**文件**: `beacon-SmsGateway/.../SubmitRespRunnable.java` (L55)
**文件**: `beacon-strategy/.../ErrorSendMsgUtil.java` (L59)

`StandardSubmit` 和 `StandardReport` 字段不完全一致，copy 后部分字段为空。

**修复**: 手动赋值或验证字段映射。

---

### 13. @Value 字段声明为 final 不会生效
**文件**: `beacon-common/.../SnowFlakeUtil.java` (L37-L44)

`final` 字段声明时初始化了，`@Value` 构造后反射设置，值被覆盖（当前默认值巧合一致但语义错误）。

**修复**: 去掉 `final` 或用构造器注入。

---

### 14. 限流只针对验证码短信
**文件**: `beacon-strategy/.../LimitOneMinuteStrategyFilter.java` (L50)

通知类（state=1）和营销类（state=2）不限制，营销短信也应有限制。

**修复**: 根据 state 配置不同限流策略。

---

### 15. 动态创建队列性能隐患
**文件**: `beacon-strategy/.../RouteStrategyFilter.java` (L117-L118)

每次发送短信都 `declareQueue`，高频操作 RabbitMQ 元数据。

**修复**: 预创建队列或用 topic exchange + routing key。

---

### 16. ThreadLocal 未在所有路径清理
**文件**: `beacon-search/.../ThreadLocalUtils.java`

ES 操作抛异常时 `remove()` 不执行，线程池环境下污染下次请求。

**修复**: finally 块中调用 `remove()`。

---

### 17. SpringUtil.getBean 反模式
**文件**: `beacon-SmsGateway/.../SubmitRespRunnable.java` (L26)
**文件**: `beacon-SmsGateway/.../DeliverRespRunnable.java` (L27-L29)

Runnable 中用静态方式获取 Spring Bean，绕过 DI，无代理（事务/AOP）。

**修复**: 构造函数传入依赖。

---

### 18. 余额校验重复
**文件**: `beacon-api/.../FeeCheckFilter.java` + `beacon-strategy/.../FeeStrategyFilter.java`

API 层预检查 + 策略层实际扣费检查，策略层检查才是必须的。

**修复**: 保留策略层，API 层可去掉。

---

## P3 - 规范改进

### 19. 拼写错误
- `MoblieCheckFilter.java` → `MobileCheckFilter`
- `execption/` 目录 → `exception/`
- `SmsGatewayStaterApp.java` → `StarterApp`

### 20. 日志不规范
- 大量 `System.out.println`（13 处，主要在 CMPP 模块）
- 大量 `e.printStackTrace()`（9 处）
- 异常用 `log.info` 记录

**修复**: 全部替换为 SLF4J log。

### 21. Raw Map 类型
多处使用 `Map` 而非 `Map<String, Object>`，编译器不警告但运行时可能 ClassCastException。

### 22. 硬编码魔法值
- 短信单价 `SINGLE_FEE = 50L`
- 计费规则 `MAX_LENGTH = 70`, `LOOP_LENGTH = 67`
- 重试时间 `DELAYED_TIME` 数组
- 时区 `"+8"` 应为 `"+08:00"`

**修复**: 迁移到 Nacos 配置。

### 23. 缺少功能
- 全局异常处理（只有 ApiIllegalException）
- 健康检查端点
- API 文档（Swagger）
- 接口幂等性（uid 去重）
- 敏感词检测未真正阻断

### 24. 技术栈过时
- Spring Boot 2.3.12 → 升级到 2.7.x 或 3.x
- Spring Cloud Hoxton → 升级到 2021.x
- JDK 8 → 升级到 11 或 17
- ES RestHighLevelClient → 已废弃，迁移到 Java Client 8.x
