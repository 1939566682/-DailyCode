## 项目整体分析
- 对 beacon-cloud 项目进行了全面分析，产出报告 `报告/项目整体分析.md`
- 项目定位：基于 Spring Cloud 微服务架构的分布式短信平台（SMS Gateway Platform）
- 技术栈：Spring Boot 2.3.12 + Spring Cloud Hoxton.SR12 + Spring Cloud Alibaba 2.2.6 + Nacos + RabbitMQ + Redis + MySQL + Elasticsearch + XXL-Job + Netty(CMPP) + Java 8
- 10 个 Maven 子模块：beacon-common(公共), beacon-api(网关:10001), beacon-strategy(策略:18883), beacon-push(推送:18885), beacon-SmsGateway(网关:18886), beacon-cache(缓存:18882), beacon-synchronization(数据同步), beacon-search(搜索:18884), beacon-monitor(监控:18887), beacon-webmaster(管理后台)
- 核心链路：Client → API(校验链) → MQ → Strategy(策略链) → MQ → Push → MQ → SmsGateway(CMPP/Netty) → 运营商
- 设计模式：策略模式+责任链（CheckFilterContext/StrategyFilterContext 动态校验链）、事件驱动(MQ解耦)、雪花算法(ID)、DFA(敏感词)
