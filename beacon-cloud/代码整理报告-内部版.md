## 二、关键文件原始状态

### 2.1 FeeStrategyFilter.java — 当前扣费逻辑

```java
@Override
public void strategy(StandardSubmit submit) {
    Long fee = submit.getFee();
    Long clientId = submit.getClientId();
    Long balance = beaconCacheClient.hIncrBy(CacheConstant.CLIENT_BALANCE + clientId, BALANCE, -fee);
    Long amountLimit = ClientBalanceUtil.getClientAmountLimit(clientId);  // 返回 -10000L
    if (balance < amountLimit) {
        beaconCacheClient.hIncrBy(CacheConstant.CLIENT_BALANCE + clientId, BALANCE, fee);
        submit.setErrorMsg(...);
        errorSendMsgUtil.sendWriteLog(submit);
        errorSendMsgUtil.sendPushReport(submit);
        throw new StrategyException(ExceptionEnums.INSUFFICIENT_BALANCE);
    }
}
```
- **问题**: hIncrBy(-fee) 和 hIncrBy(+fee) 两步不是原子的，中间宕机丢钱
- **注意**: ClientBalanceUtil 硬编码返回 -10000L

### 2.3 LimitOneMinuteStrategyFilter.java — 当前限流逻辑

```java
@Override
public void strategy(StandardSubmit submit) {
    if (submit.getState() != SmsConstant.CAPTCHA_TYPE) return;
    long sendTimeMilli = sendTime.toInstant(ZoneOffset.of("+8")).toEpochMilli();
    String key = CacheConstant.LIMIT_MINUTES + clientId + ":" + mobile;
    Boolean addResult = beaconCacheClient.zAddLong(key, sendTimeMilli, sendTimeMilli);
    if (!addResult) { /* 拒绝 — 60s 内已存在 */ }
    long start = sendTimeMilli - 59999L;
    Integer count = beaconCacheClient.zRangeByScoreCount(key, start, sendTimeMilli);
    if (count >= 2) {
        beaconCacheClient.zRemove(key, sendTimeMilli);  // 回滚写入
        throw new StrategyException(...);
    }
}
```
- **问题**: 并发时两条都 ZADD 成功，各自查到 count=2，都被拒绝
- **注意**: 小时限流类似，且有写入无法回滚的问题

### 2.5 NettyClient.java — reConnect 逻辑

```java
public void reConnect(int reConnect) {
    int times = 0;
    while (true && times < reConnect) {
        try {
            if (!isActive()) { start(); }
            else { Thread.sleep(10000); times++; }
        } catch (Exception ex) {
            System.out.println("尝试重连...");
            Thread.sleep(10000); times++;
        }
    }
}
```
- **问题**: 固定 10 次 × 10 秒，无退避；在 IO 线程阻塞

### 2.8 CMPPDecoder.java — 当前解码

```java
protected void decode(ChannelHandlerContext ctx, ByteBuf byteBuf, List<Object> list) {
    byte[] buf = new byte[byteBuf.readableBytes()];
    byteBuf.readBytes(buf);
    int totalLength = MsgUtils.bytesToInt(ArrayUtils.subarray(buf, 0, 4));
    byte[] bytes = ArrayUtils.subarray(buf, 0, totalLength);
    int commandId = MsgUtils.bytesToInt(ArrayUtils.subarray(bytes, 4, 8));
    switch (commandId) {
        case CMPP_ACTIVE_TEST: System.out.println("链路检测"); ...
        case CMPP_DELIVER: CmppDeliver d = new CmppDeliver(bytes); list.add(d);
        case CMPP_SUBMIT_RESP: CmppSubmitResp r = new CmppSubmitResp(bytes); list.add(r);
        default: System.out.println("暂无解析" + commandId);
    }
}
```
- **注意**: totalLength 可能 > buf.length 导致截断
