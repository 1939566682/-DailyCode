### P0 - 严重

#### #1 扣费非原子性
- **文件**: `beacon-strategy/src/main/java/org/example/filter/impl/FeeStrategyFilter.java`
- **行号**: L42-L49
- **状态**: ❌ 未修复
- **影响**: 资损 — 扣费后回滚前宕机，钱丢了
- **代码**:
```java
Long balance = beaconCacheClient.hIncrBy(CacheConstant.CLIENT_BALANCE + clientId, BALANCE, -fee);
if (balance < amountLimit) {
    beaconCacheClient.hIncrBy(CacheConstant.CLIENT_BALANCE + clientId, BALANCE, fee);
}
```
- **修复**: Redis Lua 脚本原子扣费+判断
```lua
local key = KEYS[1]
local field = KEYS[2]
local fee = tonumber(ARGV[1])
local limit = tonumber(ARGV[2])
local balance = redis.call('hincrby', key, field, -fee)
if balance < limit then
    redis.call('hincrby', key, field, fee)
    return 0
end
return 1
```
